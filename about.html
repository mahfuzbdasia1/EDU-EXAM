About EduExam

EduExam is a free, open educational project built so that no student or teacher ever has to pay to run a fair, digital exam. There is no premium tier, no ads, and no selling of user data.

Is it secure?

Teacher accounts are protected with a real login (email + password). Only the teacher who created an exam can view, edit, or grade it. Students never see other students' exams or results — they can only access the single exam whose key was shared with them.

Honest note: this is a lightweight classroom tool, not enterprise-grade proctoring software. It detects and logs things like tab-switching as a deterrent, but it cannot guarantee a student isn't using another device nearby, the way paid native lockdown apps attempt to.

Is it really free?

Yes — every feature is available to everyone. It runs on free hosting and a free-tier database, with no usage limits added for "upgrading."
